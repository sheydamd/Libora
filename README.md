# Libora

Libora is a library management program that was created using Python and PyQt5. The main idea behind Libora is to make managing library information easier and more organized.
Using Libora, you can manage different types of information, such as books, authors, publishers, translators, genres, and languages. Each type of information has its own section, which makes it easier to find and manage everything.

The program also has a simple and easy-to-understand interface. Users can search for information, add new records, and update existing information without much difficulty.

In general, Libora is a simple and useful program that helps organize library data and makes it easier to find and manage information.

## Menu Navigation

The menu is one of the main parts of Libora. It helps the user move between the different sections of the program. From the menu, you can open sections for books, authors, publishers, translators, genres, languages, and other library information.

The menu is designed to be simple, so users do not have to spend a lot of time looking for a specific section. Everything is organized in a clear way, and you can go from one section to another with just a few clicks.

## Main Workspace

The main workspace is the part of the program where most of the work is done. When you choose something from the menu, the main workspace changes and shows the information related to that section.

For example, when you open the Books section, you can see the books in your library and work with their information. If you open the Authors section, you can see and manage the authors instead.

This makes the program easier to use because the screen only shows the information that you need at that moment. You do not have to deal with many different windows or a lot of unnecessary information.

The sections also have a similar design. Because of this, once you understand how one section works, it is easy to understand the other sections as well.

## Managing Library Information

Libora has different sections for different types of library information. This helps keep everything organized and makes it easier to manage the data.

The program allows you to manage:

- Books
- Authors
- Publishers
- Translators
- Genres
- Languages
- Book resources and sources
- ESRB ratings

In each section, you can see the records that have already been added. You can also add new records, search for existing ones, edit their information, or remove records that you no longer need.

For example, if you want to add a new book, you can go to the Books section and add its information. If some information is wrong, you can edit it later without needing to create the record again.

This makes it much easier to keep the library information organized and updated.

### Search

The search feature is useful when there are many records in the library. Instead of looking through the whole list, you can simply type the name or other information you are looking for.

As you type, Libora filters the list and shows the records that match your search. This helps you find information much faster.

For example, if you have a large number of books, you do not need to scroll through every book to find one specific title. You can just type the title in the search box and find it quickly.

### Adding a New Record

Adding a new record in Libora is also very simple. Each section has an Add button that can be used to create a new record.

When you click the button, a small window appears with the fields you need to fill in. The fields are different depending on what you are adding.

For example, when adding a book, you can enter information about the book. When adding an author, you can enter the author's information instead.

After filling in the information, you can save the record. The new record will then appear in the list.

The process is simple: click Add, enter the information, save it, and continue working.

Editing and Removing Records

Libora also allows users to change or remove existing records. If you make a mistake or if some information changes, you can edit the record instead of adding a new one.

You can also remove records that are no longer needed. This helps keep the library database clean and organized.

## Main Features

### Book Management

Libora allows you to add and manage books in your library. You can store important information about each book and find it later using the search feature.

### Author Management

You can keep information about the authors of your books in a separate section. This makes it easier to find and manage author information.

### Publisher Management

The publisher section helps you store information about the publishers connected to your books.

### Translator Management

If a book has a translator, you can store and manage the translator's information in the translator section.

### Genre Management

You can create and manage different genres, such as fiction, history, science, or other types of books. This helps you organize your collection better.

### Language Management

The language section allows you to keep information about the languages used in your library. This can be useful when your library contains books in different languages.

### Resource Management

Libora also allows you to manage additional resources and sources related to your books. This helps keep extra information connected to the right records.

### ESRB Management

The program includes an ESRB section where you can store and manage ESRB ratings when they are needed.

### Quick Search

The search feature makes it faster to find a specific record. You can search instead of manually going through a long list.


### Local Data Storage

The library information can be stored locally on the computer. This allows the user to keep the data available without needing to use an online service.

### Simple and Clean Interface

Libora has a clean and simple interface. The different sections are clearly separated, and the user can easily understand where to go and what to do.


The main goal of Libora is to provide a simple and organized way to manage library information without making the user deal with complicated menus or unnecessary steps.
